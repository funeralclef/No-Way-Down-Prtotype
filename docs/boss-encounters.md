# Final guardians

The dynamic encounter implementation, arena footprints, device skills and
validation are documented in [dynamic-combat.md](dynamic-combat.md).

The fourth hold selects one of three guardians per run. Defeating both phases
unlocks the existing finish/continue decision. Later arenas retain the normal
wave progression. Models are original native meshes in `art/bosses`, rebuilt
with `tools/build_boss_models.py`.
